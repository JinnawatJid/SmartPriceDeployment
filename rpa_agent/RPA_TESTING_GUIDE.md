# คู่มือการทดสอบระบบ Client-Side RPA Agent (Developer / QA)

เอกสารฉบับนี้อธิบายขั้นตอนการทดสอบ (Testing Workflow) สำหรับนักพัฒนาหรือ QA เพื่อตรวจสอบการทำงานของสถาปัตยกรรม Client-Side RPA ตัวใหม่ (Agent + Chrome Debugging) บนเครื่อง Local ของคุณ

---

## 1. การสร้างและคอมไพล์ Agent (ทำบนเครื่องที่มีอินเทอร์เน็ต)

**สำคัญมาก:** ขั้นตอนนี้สำหรับ Developer / ทีม IT เท่านั้น เพื่อสร้างไฟล์โปรแกรม `.exe` ที่ไม่ต้องพึ่งพาอินเทอร์เน็ตในการทำงานบนเครื่องสาขา

1. **เปิด Command Prompt** (Terminal) และเข้าไปที่โฟลเดอร์ `rpa_agent`
   ```cmd
   cd rpa_agent
   ```
2. **สร้างไฟล์ Executable (.exe):** รันสคริปต์ `build_agent.bat`
   ```cmd
   build_agent.bat
   ```
   *(รอจนกว่าระบบจะสร้าง Virtual Environment, โหลด Dependencies (FastAPI, Selenium) ผ่านอินเทอร์เน็ต และคอมไพล์ด้วย PyInstaller เมื่อเสร็จสิ้นจะแสดง [SUCCESS] Build complete!)*

   *(เมื่อเสร็จแล้ว ระบบจะสร้างโฟลเดอร์ `dist` และไฟล์ `rpa_agent.exe` เอาไว้ด้านใน)*

3. **การเตรียมไฟล์เพื่อส่งให้สาขา (ZIP):**
   เพื่อความง่ายที่สุด ให้คุณคลิกขวาที่โฟลเดอร์ `rpa_agent` ทั้งโฟลเดอร์ แล้วทำการ **Zip** ไฟล์ทั้งหมด (เช่น `rpa_agent.zip`) และส่งไฟล์ ZIP นี้ไปยังเครื่องคอมพิวเตอร์ที่สาขา (ผ่าน Flash Drive หรือ Network)

---

## 2. การจำลองการใช้งานบนเครื่องสาขา (Offline)

ในขั้นตอนนี้ เราจะทำตัวเสมือนเป็นพนักงานหน้าสาขาที่ได้รับไฟล์ `rpa_agent.zip` มาแล้ว (เครื่องสาขา**ไม่จำเป็น**ต้องมีอินเทอร์เน็ตเพื่อโหลด Python packages ใดๆ ทั้งสิ้น)

1. **พนักงานสาขาแตกไฟล์ (Extract):**
   ให้พนักงานสาขา Extract ไฟล์ `rpa_agent.zip` ไปไว้ที่หน้า Desktop หรือ Drive D: ตามสะดวก

2. **รัน Local Agent และเบราว์เซอร์:**
   เข้าไปในโฟลเดอร์ `rpa_agent` ที่เพิ่งแตกไฟล์ออกมา จากนั้นดับเบิลคลิกที่ไฟล์:
   ```cmd
   start_agent_and_chrome.bat
   ```
   - สคริปต์นี้จะฉลาดพอที่จะเข้าไปหาไฟล์ `rpa_agent.exe` (ในโฟลเดอร์ `dist` หรือโฟลเดอร์ปัจจุบัน) เพื่อรันหน้าต่าง **Command Prompt สีดำ** (พอร์ต 8001) ขึ้นมา **(พนักงานต้องห้ามปิดหน้าต่างสีดำนี้เด็ดขาด)**
   - และระบบจะเปิดหน้าต่าง **Google Chrome สีขาว** ขึ้นมาพร้อมเปิดพอร์ต `--remote-debugging-port=9222` โดยอัตโนมัติ

2. **เตรียมข้อมูลใน Dynamics 365 BC:**
   - สลับไปที่หน้าต่าง **Google Chrome** สีขาวที่เปิดขึ้นมา
   - เข้าสู่ระบบ (Login) Dynamics 365 BC ของคุณ
   - ไปที่เมนู หรือหน้าต่างรายการ **"Sales Quotes" (ใบเสนอราคาขาย)** และเปิดหน้านั้นทิ้งไว้

## 3. การรัน Web Application (Smart Pricing)

**สำคัญมาก (สำหรับ Google Chrome):** เนื่องจาก Smart Pricing รันผ่าน IP ภายใน (เช่น `http://192.168.x.x`) แต่ตัว Agent รันที่ `localhost` Chrome จะมองว่าเป็นการข้าม Network แบบไม่ปลอดภัย (Private Network Access) คุณต้องเข้าไปตั้งค่าเพื่ออนุญาตก่อน:
1. เปิดเบราว์เซอร์ Chrome ที่จะใช้เข้าเว็บ Smart Pricing
2. พิมพ์ URL นี้ลงในช่อง Address Bar: `chrome://flags/#block-insecure-private-network-requests`
3. เปลี่ยนค่า `Block insecure private network requests` ให้เป็น **Disabled**
4. กดปุ่ม Relaunch (มุมขวาล่าง) เพื่อรีสตาร์ทเบราว์เซอร์

---

## 3. การรัน Web Application (Smart Pricing)

1. **เปิด Terminal หน้าต่างใหม่ (หน้าต่างที่ 2)** เพื่อรัน Backend
   ```cmd
   cd backend
   venv\Scripts\activate  (หรือ \Scripts\activate สำหรับ Windows)
   uvicorn main:app --reload --port 8000
   ```
2. **เปิด Terminal หน้าต่างใหม่ (หน้าต่างที่ 3)** เพื่อรัน Frontend
   ```cmd
   cd frontend
   npm run dev
   ```
   *(ตัวแอปจะเปิดขึ้นมาที่พอร์ต `5173` หรือ `3000` ตามการตั้งค่าของ Vite)*

---

## 4. การจำลอง Flow การส่งข้อมูลจาก Web App ไปยัง D365

1. เปิดเบราว์เซอร์ (สามารถใช้ Chrome อันไหนก็ได้) และเข้าไปที่ URL ของ Frontend (เช่น `http://localhost:5173`)
2. สร้าง **ใบเสนอราคาใหม่**:
   - เลือกชื่อลูกค้า
   - เลือกรูปแบบการจัดส่ง (เช่น รับเอง หรือ จัดส่ง)
   - เพิ่มรายการสินค้า (ทดลองเพิ่มทั้งกระจกและอลูมิเนียมเพื่อดูการคำนวณราคา)
3. ดำเนินการไปจนถึงหน้า **Step 6 (สรุปยอด)**
4. กดปุ่ม **"ยืนยัน" (Save/Confirm)** สีแดง
5. เมื่อยืนยันเสร็จ ปุ่มจะเปลี่ยนเป็นสีน้ำเงินคำว่า **"ส่งเข้า Dynamics 365"** ให้กดปุ่มนั้น
6. **[สังเกตผลลัพธ์]**:
   - กลับไปดูที่หน้าต่าง Chrome ที่เปิด D365 BC ทิ้งไว้ (จากขั้นตอนที่ 2.2)
   - ระบบ RPA จะต้องเริ่มทำการคลิกปุ่ม "+New", กรอกข้อมูลลูกค้า, พนักงานขาย, และรายการสินค้าให้โดยอัตโนมัติ

## 5. จุดที่ควรสังเกตระหว่างการทดสอบ (Checklist)

- [ ]  หน้าต่าง Command Prompt สีดำ (RPA Agent) แสดง Log ว่าได้รับ Request และแสดงรายการสินค้าถูกต้อง
- [ ]  ระบบสามารถค้นหาและสลับ (Switch tab) ไปยังหน้าจอ Sales Quotes ใน D365 ได้ถูกต้อง แม้จะเปิดไว้หลายแท็บ
- [ ]  การกรอก Customer No. และ Sales Admin ถูกต้องและหาข้อมูลเจอ
- [ ]  สินค้าระบุปริมาณ (Quantity) ถูกต้อง
- [ ]  กรณีเป็นสินค้าหมวดกระจก (G) ระบบกรอกราคาต่อตารางฟุต (Sq.ft) และราคาต่อแผ่น (Sheet) ได้ถูกต้อง
- [ ]  กรณีเป็นสินค้าทั่วไป ระบบกรอกราคา Unit Price ได้ถูกต้อง
- [ ]  เมื่อทำงานเสร็จสมบูรณ์ จะมี Alert แจ้งเตือนความสำเร็จบนหน้าเว็บ Smart Pricing

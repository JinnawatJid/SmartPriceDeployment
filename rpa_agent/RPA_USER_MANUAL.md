# คู่มือการใช้งานระบบสร้างใบเสนอราคาอัตโนมัติ (RPA Agent)
*(สำหรับพนักงานสาขา)*

ระบบ **RPA Agent** คือโปรแกรมผู้ช่วยอัจฉริยะที่ติดตั้งอยู่บนเครื่องคอมพิวเตอร์ของคุณ ทำหน้าที่เชื่อมต่อข้อมูลจากระบบประเมินราคา (Smart Pricing) เพื่อพิมพ์ข้อมูลใบเสนอราคาลงในระบบ **Dynamics 365 Business Central (D365 BC)** ให้โดยอัตโนมัติ

## 1. การติดตั้งและเตรียมความพร้อม

*คุณจะต้องทำขั้นตอนนี้เพียง **ครั้งแรกครั้งเดียว** เท่านั้น*

1. ดาวน์โหลดไฟล์ **`RPA_Agent.zip`** ที่ได้รับจากทีม IT หรือส่วนกลาง
2. แตกไฟล์ (Extract All) ไปไว้ในโฟลเดอร์ที่คุณต้องการ (เช่น แฟลชไดร์ฟ หรือหน้า Desktop)
3. ภายในโฟลเดอร์ คุณจะพบไฟล์ 2 ไฟล์หลักที่สำคัญคือ:
   - `start_agent_and_chrome.bat` (ตัวเปิดระบบ)
   - โฟลเดอร์ `dist` ซึ่งมีโปรแกรม `rpa_agent.exe` อยู่ด้านใน

*(ข้อแนะนำ: ไม่ควรลบหรือย้ายไฟล์ใดๆ ออกจากโฟลเดอร์นี้)*

## 2. การเปิดใช้งานในแต่ละวัน (Daily Routine)

*ในทุกๆ วันที่คุณต้องการสร้างใบเสนอราคาอัตโนมัติ ให้ทำตามขั้นตอนนี้ก่อนเริ่มงาน:*

1. ดับเบิลคลิกที่ไฟล์ **`start_agent_and_chrome.bat`** (ไอคอนรูปฟันเฟือง)
2. ระบบจะเปิดหน้าต่างขึ้นมา 2 อย่าง **(ห้ามปิดหน้าต่างสีดำเด็ดขาด)**:
   - **(1) หน้าต่างสีดำ (Command Prompt):** เป็นโปรแกรมผู้ช่วย RPA Agent ที่จะคอยรับคำสั่ง
   - **(2) หน้าต่าง Google Chrome สีขาว:** เป็นโปรแกรมเบราว์เซอร์ที่จะถูกควบคุมโดยอัตโนมัติ
3. ในหน้าต่าง **Google Chrome สีขาว** ที่เปิดขึ้นมาใหม่ ให้คุณเข้าไปที่เว็บไซต์ระบบ **Dynamics 365 BC**
4. ลงชื่อเข้าใช้งาน (Login) ตามปกติของคุณ
5. เปิดไปที่หน้ารายการ **"Sales Quotes" (ใบเสนอราคาขาย)** รอเอาไว้

*หมายเหตุ: คุณสามารถย่อหน้าต่าง (Minimize) ตัวเบราว์เซอร์สีดำทิ้งไว้ด้านล่างได้ตลอดทั้งวันตราบใดที่คุณยังไม่ปิดเครื่อง*

## 3. ขั้นตอนการทำงานร่วมกับ Smart Pricing

เมื่อคุณเตรียม Chrome ในขั้นตอนที่ 2 เรียบร้อยแล้ว คุณสามารถเริ่มทำงานในระบบประเมินราคาได้ทันที

1. เปิดเว็บไซต์ประเมินราคา (Smart Pricing) ของคุณในเบราว์เซอร์ใดก็ได้
2. ทำการเลือกชื่อลูกค้า เลือกระยะทางการจัดส่ง และเพิ่มรายการสินค้าตามปกติ
3. ไปที่หน้า **Step 6: สรุปยอด**
4. เมื่อตรวจสอบข้อมูลถูกต้องครบถ้วนแล้ว ให้กดปุ่ม **"ยืนยัน"** สีแดง (หรือ Save Draft)
5. ปุ่มด้านล่างสุดจะเปลี่ยนเป็นปุ่มสีน้ำเงินคำว่า **"ส่งเข้า Dynamics 365"** ให้กดที่ปุ่มนั้น
6. หน้าต่างสีดำ (Agent) จะเริ่มแสดงข้อความการทำงาน และ **Google Chrome ในขั้นตอนที่ 2 จะเริ่มขยับและพิมพ์ข้อมูลให้คุณโดยอัตโนมัติ**
7. รอจนกว่าระบบจะแจ้งเตือนว่า **"ส่งข้อมูลเข้า Dynamics 365 ผ่าน RPA เรียบร้อยแล้ว"** บนหน้าเว็บ Smart Pricing

## 4. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

**ปัญหา:** กดปุ่มส่งเข้า BC แล้วขึ้นข้อความว่า "ส่งข้อมูลเข้า Dynamics 365 ไม่สำเร็จ - โปรดตรวจสอบว่า RPA Agent บนเครื่องเปิดอยู่หรือไม่"
**วิธีแก้ไข:**
- ตรวจสอบให้แน่ใจว่าคุณได้เปิดใช้งานไฟล์ `start_agent_and_chrome.bat` แล้ว
- หากหน้าต่างหน้าต่างสีดำ (RPA Agent) หายไป ให้กดเปิด `start_agent_and_chrome.bat` ใหม่อีกครั้ง

**ปัญหา:** Chrome พยายามสร้างใบเสนอราคา แต่พิมพ์ข้อมูลลงช่องผิด หรือค้าง
**วิธีแก้ไข:**
- ปิดเบราว์เซอร์ Chrome และปิดหน้าต่างสีดำ
- เปิดโปรแกรมใหม่ด้วยไฟล์ `start_agent_and_chrome.bat`
- ตรวจสอบให้แน่ใจว่าแท็บหน้าจอที่เปิดค้างไว้คือหน้าจอ "Sales Quotes" จริงๆ ไม่ใช่หน้าต่างอื่นใน Dynamics 365

**ปัญหา:** กด `start_agent_and_chrome.bat` แล้ว Chrome ไม่เปิดขึ้นมา
**วิธีแก้ไข:**
- อาจเกิดจากคอมพิวเตอร์ของคุณไม่ได้ติดตั้ง Google Chrome เอาไว้ หรือติดตั้งไว้ในโฟลเดอร์ที่โปรแกรมหาไม่เจอ กรุณาติดต่อทีม IT

**ปัญหา:** กดปุ่มส่งเข้า BC แล้วหน้าต่าง Chrome เปิดหน้าใหม่ขึ้นมาแทนที่จะพิมพ์ใน Dynamics 365
**วิธีแก้ไข:**
- ตรวจสอบให้แน่ใจว่าคุณได้ **เข้าสู่ระบบ Dynamics 365 BC** ทิ้งไว้เรียบร้อยแล้วบนหน้าต่าง Chrome ตัวที่ระบบเปิดขึ้นมาให้ (ห้ามใช้ Chrome ที่เปิดด้วยตัวเอง)
